# TODO guide for the Connect Four A2 starter

Search the project for `TODO A2-`.

The TODO markers are deliberately aligned with the assignment rubric.

## Rubric-aligned TODO areas
- **MVC**: application setup, division of view/controller responsibilities, model notifications, cleaner separation of concerns
- **Strategy**: player/opponent abstraction, random/greedy players, GUI selection of strategy type
- **Command**: move commands, undo, redo, command history
- **Functionality**: valid moves, win/draw logic, restart, save, load
- **GUI quality**: board rendering, status messages, controls, usability improvements
- **Testing**: expand the supplied JUnit tests for model behaviour

## A reasonable student workflow
1. Study `mvcexample`
2. Run the starter GUI
3. Complete the core Connect Four model
4. Improve the board visuals and status updates
5. Refactor controller responsibilities
6. Implement Strategy cleanly
7. Implement Command-based undo/redo
8. Add save/load
9. Add more tests
10. Refactor for readability and maintainability
